# M1 到正式实验的工程准备记录

完成日期：2026-11-01。结论：本轮工程基础与批准门禁已建立，实验协议未批准，不能据此直接启动正式搜索或最终测试。

## 完成的工程改动

保留 run_smoke.py 的命令入口及 sample_dataset、score_metrics、validate_record 可调用接口。数据、模型、评估、校验与存储拆为独立模块，P2/P3 公共代码保持不变。

抽样特征矩阵改为原位缓冲，新增未来 train/val 全量磁盘映射装载组件。模型输入校验特征白名单、维数、有限值与二分类标签；只允许训练折拟合，沿用 P2 样本权重，拒绝重复类别加权。攻击分数按 classes_ 找到类别 1，不假设列位置。

Smoke 强校验拒绝不一致 accuracy、混淆矩阵、AP/ROC、分类别支持数、缺失数据身份、空时延对象、错误计时公式及 bootstrap 比较。预测校验只使用保存的数据，检查行 ID 摘要、标签、攻击族、attempted 与分数。新增完整攻击族缺失报告与共享计时行 ID 接口。

运行目录使用唯一 ID、排他文件创建、完成清单及逐文件 SHA256。失败与准备计划有不同状态。历史真实 Smoke 产物未覆盖，新运行不再只把模型和预测放入临时目录。

正式准备入口只校验团队协议或创建计划，不执行数据加载、搜索、训练和测试评估。所有未批准实验选项保持 null。门禁对批准记录和摘要做一致性检查，不替代真实团队审批。

## 本轮验证

- 全部 75 项短时测试通过：原有 47 项，新增加 28 项 M1 测试；本次 unittest 报告约 3.84 秒。
- 新增测试覆盖白名单、训练/验证隔离、P2 权重传递、正类分数、种子隔离、抽样批次不变性、缺失攻击族、计时 ID、损坏记录拒绝、文件哈希及不覆盖策略、协议批准门禁。
- 合成数据端到端集成测试：40 行训练、24 行验证，RF 3 棵树、GBDT 3 轮，保存、重载、指标、PR 图和独立预测复算全部通过。

- 历史真实 Smoke JSON 与保存预测通过加强后的兼容校验；没有重新运行其真实数据训练。
- pip check 无冲突；正式协议模板实际运行结果为 BLOCKED，这是预期门禁行为。
- 未修改 src/、eval/ 或原有 P2/P3 测试；未读取真实测试集，未运行正式超参搜索、全量训练或 M2 深度模型。
