# P6 实验结果与交接说明

已读取实际搜索结果、十份自编码器结果、四份辅助方法结果和 P5 验证集权重复跑报告。最终只读核查已通过，证据和环境明细见 docs/p6_acceptance/final_audit.json。本说明未重新训练模型，也不替代 P7 验收签字。

## 主实验结果

数据为 original / stratified / main，140 维。正式搜索完成 8 配置 × 5 种子共 40 次拟合，获选 A06，良性验证 MSE 均值为 0.0058559867。结构为 140–128–32–128–140，学习率 0.0003，无权重衰减。

每次使用 1,466,743 条 P2 负类训练样本和 302,963 条负类验证样本。负类定义沿用 P2 的 y_binary=0，不自行调整 attempted 映射。阈值标定阶段未使用 Test；最终评估单独读取 Test。

测试集共 346,544 条，负类 282,506 条，攻击 64,038 条。

五种子 AP 为 0.742710 ± 0.006170，ROC-AUC 为 0.904003 ± 0.003109。此处及下表的 ± 为五种子样本标准差，ddof=1。

| 指标 | 验证良性 q95 阈值 | 验证良性 q99 阈值 |
|---|---:|---:|
| 攻击召回率 TPR | 61.44% ± 1.31 个百分点 | 52.27% ± 1.80 个百分点 |
| 误报率 FPR | 4.84% ± 0.17 个百分点 | 0.83% ± 0.14 个百分点 |
| Precision | 74.20% ± 0.75 个百分点 | 93.47% ± 0.88 个百分点 |
| Accuracy | 88.93% ± 0.27 个百分点 | 90.50% ± 0.24 个百分点 |
| Macro F1 | 0.8028 ± 0.0057 | 0.8074 ± 0.0072 |

q99 相比 q95 平均降低误报率约 4.01 个百分点，同时损失约 9.17 个百分点攻击召回率。必须保留两个预定阈值版本；不能依据 Test 表现回头调阈值或重新选配置。

AP 与 ROC-AUC 来自连续异常分数，不依赖 q95/q99 的二元判定，所以同一 seed 两个阈值版本的 AP、ROC-AUC 相同是正常的。固定阈值的实际 TPR/FPR 与 P3 的经验 ROC 上 TPR@指定FPR 是不同量，汇总时不能互换名称。

## 辅助对照

| 方法 | AP | ROC AUC | q95 TPR | q95 FPR | q99 TPR | q99 FPR |

| Isolation Forest | 0.5828 | 0.7931 | 57.76% | 5.28% | 37.24% | 1.00% |
| One Class SVM | 0.5046 | 0.7485 | 49.65% | 4.71% | 8.10% | 0.96% |

辅助方法各拟合一次，共用 seed=42 的最多 10,000 条负类训练样本；未进行五种子统计。自编码器使用全量负类训练，比较结论应限定在本次各自训练设置下，不应解释为同数据量或同搜索预算的严格胜负。

## 计算成本与局限

A06 五次训练平均 347.54 ± 36.62 秒，含训练期的良性验证与早停选择；18–21 个 epoch。这不是全部 40 次搜索的总耗时。

五种子平均摊销 CPU 推理成本为 0.001746 ± 0.000274 毫秒每流，使用 batch=512、预热5次、重复30次、单线程。它不是 batch=1 的单请求响应延迟，跨方法比较还要确认相同机器和设置。

q95 下各攻击族五种子平均召回差异很大：DoS Slowhttptest 94.26%，DoS Hulk 90.91%，botnet 10.32%，portscan 4.43%，SQL injection 0%。Heartbleed 与 infiltration 虽为 100%，支持数仅2与5，不能作强泛化结论。当前实验未设计专门的未知攻击族留出，不能写成已验证未知攻击检测能力。
